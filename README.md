## ⚡ Parallel & GPU Computing

This repository contains my **Parallel & GPU Computing Lab** work, including practical experiments, benchmarking, performance analysis and a mini project.

The work explores how computational problems can be divided and executed simultaneously using different parallel programming techniques.
