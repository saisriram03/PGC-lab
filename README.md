# 🌌⚡ PARALLEL & GPU COMPUTING LAB

> 🚀 **A complete practical journey from Sequential Computing → Multithreading → Distributed Computing → GPU Acceleration**

This repository contains the practical work completed for the **Parallel and GPU Computing Laboratory**.

The experiments focus on understanding how computational workloads can be divided, executed in parallel, benchmarked, and optimized.
