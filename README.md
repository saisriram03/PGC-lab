## 🚀 About This Lab

This repository contains my **Parallel & GPU Computing Lab** work, including practical experiments, benchmarking studies, performance analysis and a mini project.

The laboratory explores different approaches to parallel computation, starting from **sequential execution** and progressing towards **multithreading, shared-memory parallelism, distributed computing and GPU acceleration**.
